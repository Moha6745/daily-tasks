# تشغيل «تحدي الـ 30» على Expo Go

التطبيق نفسه ويب (PWA) لا React Native، و Expo Go لا يفتح إلا حِزَم React
Native. فهذا المجلّد غلافٌ رقيق: تطبيق Expo وظيفته الوحيدة فتح الموقع في
`WebView` يملأ الشاشة. لا منطق للمهام فيه ولا تخزين — كلّه يبقى في الويب.

## الخطوات

على الحاسوب (ليس على جهاز الجلسة السحابية — الهاتف يحتاج خادماً يصل إليه):

```bash
git clone https://github.com/moha6745/daily-tasks.git
cd daily-tasks/mobile
npm install
npx expo start
```

ثم على الآيفون: ثبّت **Expo Go** من App Store، وافتح تطبيق **الكاميرا** ووجّهه
إلى رمز QR الذي طبعه الأمر في الطرفية. سيُفتح التطبيق في Expo Go.

إن كان الهاتف والحاسوب على شبكتين مختلفتين (أو كانت شبكة الحاسوب تعزل
الأجهزة عن بعضها) فاستعمل النفق:

```bash
npm run start:tunnel
```

## فتح نسخة محلية بدل الإنتاج

الغلاف يفتح الإنتاج افتراضياً (`https://daily-tasks-a27.pages.dev`)، فيعمل بلا
إعداد ويبقى محدَّثاً مع كل نشرة. ولتجربة تعديل قبل نشره: شغّل
`npm run dev` أو `npm run dev:static` في جذر المستودع، ثم مرّر عنوان الحاسوب
على الشبكة — لا `localhost` فهو يعني الهاتف نفسه:

```bash
EXPO_PUBLIC_APP_URL=http://192.168.1.5:8080 npx expo start
```

## ما لا يعمل داخل الغلاف

الغلاف يفتح الموقع في `WKWebView`، وهي لا تطابق Safari في كل شيء:

- **لا عمل دون اتصال.** عامل الخدمة لا يُسجَّل في `WKWebView` إلا لنطاقات
  مُعلَنة في بنية التطبيق، فيفشل التسجيل بصمت (التطبيق يتوقّع ذلك ويعمل
  بدونه) ويحتاج كل فتح إلى شبكة.
- **لا إشعارات.** `Notification` من الويب لا تعمل داخل الغلاف، فتذكيرات
  الصلاة والمهام لا تظهر.
- **البوصلة قد لا تدور.** إذن حسّاسات الحركة
  (`DeviceOrientationEvent.requestPermission`) غير مضمون في `WKWebView`؛
  اتجاه القبلة بالدرجات يظهر على كل حال فهو محسوب من الموقع لا من الحسّاس.

**والأبسط من هذا كلّه**: افتح `https://daily-tasks-a27.pages.dev` في Safari،
ثم «مشاركة» ← **«إضافة إلى الشاشة الرئيسية»**. تحصل على أيقونة وشاشة كاملة
وعملٍ دون اتصال وإشعارات (iOS 16.4+) بلا حاسوب ولا Expo ولا خادم يعمل.
الغلاف هنا لمن يريد تجربته في Expo Go أو بناءه تطبيقاً أصيلاً لاحقاً.

## ملاحظة على الإصدار

Expo Go لا يدعم إلا أحدث إصدار من SDK، وهذا الغلاف على **SDK 58**
(`react-native-webview` 14.0.1 كما تُحدّده `bundledNativeModules.json` في
الإصدار نفسه). فإن صدر إصدار أحدث ورفض Expo Go فتحه:

```bash
npx expo install expo@latest --fix
```
