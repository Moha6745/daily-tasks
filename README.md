# تحدي الـ 30 — تطبيق المهام والعادات اليومية

تطبيق ويب عربي (RTL) لإدارة المهام والعادات اليومية ضمن تحدٍّ مدته ثلاثون يوماً،
مع مواقيت الصلاة واتجاه القبلة محسوبة محلياً على الجهاز.

يعمل التطبيق بالكامل في المتصفح: لا خادم، ولا قاعدة بيانات، ولا تُرسل أي بيانات خارج الجهاز.

---

## المزايا

### الواجهة الرئيسية
- **بطاقة اليوم**: اسم اليوم، التاريخ الهجري (أم القرى) والميلادي، الصلاة القادمة والوقت المتبقي عليها.
  بالضغط عليها تُفتح صفحة المواقيت والقبلة.
- **شريط تحدي الـ 30**: رقم اليوم الحالي، نسبة إنجاز اليوم، وحالة أيام الأسبوع الجاري.
- **خانات المهام الثلاث** بالترتيب: اليومية، ثم الأسبوعية، ثم الشهرية.
- عند الضغط على الدائرة الفارغة بجانب المهمة تُشطب بخط وتنزل تلقائياً إلى أسفل القائمة.
- شريط إضافة سريعة أسفل القوائم يضيف المهمة بتاريخ اليوم مباشرة.

### قاعدة تصنيف المهام
| تاريخ المهمة | الخانة |
|---|---|
| اليوم (وهو الافتراضي عند الإضافة) | **المهام اليومية** |
| من الغد وحتى يوم السبت من الأسبوع نفسه | **المهام الأسبوعية** |
| بعد سبت هذا الأسبوع | **المهام الشهرية** |
| تاريخ مضى ولم تُنجز المهمة | المهام اليومية، بوسم «متأخرة» |
| مهمة متكررة | المهام اليومية، كل يوم |

يظهر تاريخ كل مهمة بجانبها في الخانتين الأسبوعية والشهرية. الأسبوع يبدأ الأحد وينتهي السبت.

### إضافة المهام
- التاريخ تلقائياً اليوم، مع أزرار سريعة (اليوم / غداً / تاريخ لاحق) وتقويم لتاريخ مخصّص.
- مؤشّر مباشر يوضّح الخانة التي ستُضاف إليها المهمة قبل الحفظ.
- **خيار التكرار اليومي**: تظهر المهمة تلقائياً كل يوم، ويُسجَّل إنجازها لكل يوم على حدة.
- تصنيف اختياري (ديني، عمل، صحة، تعلّم) ووقت تذكير اختياري.

### مواقيت الصلاة والقبلة
- حساب فلكي محلي كامل دون اتصال بالإنترنت.
- طرق الحساب: أم القرى، رابطة العالم الإسلامي، الهيئة المصرية، كراتشي، ISNA، دبي.
- مذهب العصر: الجمهور أو الحنفي.
- عدّاد تنازلي للصلاة القادمة ونسبة ما انقضى من الفترة الحالية.
- بوصلة القبلة بزاوية الدائرة العظمى والمسافة إلى مكة المكرمة، مع دعم حساس الاتجاه في الجهاز.

### الإعدادات
- إذن الموقع وإذن الإشعارات يُطلبان **مرة واحدة فقط** عند أول دخول، ويمكن تعديلهما لاحقاً من الإعدادات.
- تذكير بداية اليوم (الفجر) وتذكير نهاية اليوم (11:00 ليلاً افتراضياً) بأوقات قابلة للتعديل.
- تنبيهات مواقيت الصلوات الخمس بمدة استباقية تختارها.
- الوضع الداكن: تلقائي حسب الجهاز، أو فاتح/داكن دائماً.
- اختيار المدينة يدوياً لمن لا يرغب بمشاركة موقعه (26 مدينة جاهزة).
- تصدير البيانات بصيغة JSON، وحذف كل البيانات من الجهاز.

## التشغيل

التطبيق ملفات ثابتة ويحتاج خادماً بسيطاً لأن الشيفرة مقسّمة إلى وحدات ES Modules
(فتح `index.html` مباشرة من القرص لن يعمل بسبب قيود CORS):

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

يمكن نشره كما هو على أي استضافة ملفات ثابتة.
للنشر على Cloudflare Pages راجع [`DEPLOY.md`](DEPLOY.md) — يشرح إعداد بيانات الاعتماد
مرة واحدة ثم `npm run deploy`.

> للحصول على الموقع الجغرافي والإشعارات وتثبيت التطبيق، يجب أن يُقدَّم عبر
> `https://` أو `localhost` — وهو شرط من المتصفح لا من التطبيق.

## تسجيل الدخول عبر Google و Apple

الأزرار جاهزة في شاشة الدخول لكنها معطّلة حتى تُضاف المعرّفات في
[`assets/js/config.js`](assets/js/config.js):

```js
export const AUTH_CONFIG = {
  googleClientId: 'xxxxxxxx.apps.googleusercontent.com',
  appleClientId: 'com.example.tahaddi30.service',
  appleRedirectURI: 'https://example.com/',
};
```

- **Google**: أنشئ OAuth Client ID من نوع Web في Google Cloud Console،
  وأضف نطاق موقعك ضمن *Authorized JavaScript origins*.
- **Apple**: أنشئ Services ID من Apple Developer، وسجّل `appleRedirectURI` نفسه
  ضمن *Return URLs* (يتطلب HTTPS).

ما دامت القيم فارغة، يمكن استخدام التطبيق كاملاً عبر **الدخول كضيف**،
وتُحفظ كل البيانات في `localStorage` على الجهاز.

## حدود معروفة

- **الإشعارات في الخلفية**: متصفحات الويب لا تسمح بجدولة إشعارات والتطبيق مغلق دون خادم Push.
  تعمل التذكيرات ما دام التطبيق مفتوحاً (ولو في تبويب خلفي)، وتُعاد جدولتها عند كل فتح.
  لتجربة أقرب للتطبيق الأصلي، ثبّت التطبيق على الشاشة الرئيسية (PWA).
- **التقويم الهجري** يعتمد على `Intl` في المتصفح (أم القرى)؛ إن لم يدعمه المتصفح يُعرض التاريخ الميلادي وحده.
- **خطوط العرض العالية**: في المواسم التي لا تغيب فيها الشمس أو لا تطلع، تُعرض بعض المواقيت
  كـ«غير متاح» بدل تقدير قد يكون مضلّلاً، مع اقتراح تغيير طريقة الحساب.
- **البوصلة** تحتاج حساس اتجاه في الجهاز؛ على iOS يُطلب الإذن صراحةً. بدونه تُعرض الزاوية رقمياً.
- البيانات محلية لكل متصفح ولا تُزامن بين الأجهزة.
